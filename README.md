# Data & Cloud Bootcamp — Devlights 5.0

Repositorio para el seguimiento de clases, laboratorios y prácticas de los módulos de bases de datos, SQL y entornos cloud.

---

## 🛠️ Stack Tecnológico & Entorno Local

* **Base de Datos:** PostgreSQL 15+
* **Gestión UI:** pgAdmin 4
* **Contenedorización:** Docker & Docker Compose

### Comandos de Control (Docker Compose)
```bash
# Iniciar servicios en segundo plano
docker compose up -d

# Ver estado de los contenedores
docker compose ps

# Ver logs en tiempo real
docker compose logs -f

# Apagar y remover contenedores (conservando volúmenes)
docker compose down

```
